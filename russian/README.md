# Русификатор Spamton Subplot для Nintendo Switch

Переводит на русский язык весь текст игры: меню, настройки, предметы и их описания, достижения, советы, имена врагов, интерфейс, титры и песню Гастера. Схема управления в главном меню тоже заменяется на русскую.

Шрифт игры («Determination RUS by Lyajka») уже содержит кириллицу, поэтому текст выглядит так же, как в оригинале.

## Установка

1. Установите сам порт: `SpamtonSubplot.nro` должен лежать на SD-карте в `/switch/spamton_subplot/` (см. основной README).
2. Скопируйте папку `lang` из этой папки целиком на SD-карту в `/switch/spamton_subplot/`.

Должно получиться так:

```
SD-карта
└── switch
    └── spamton_subplot
        ├── SpamtonSubplot.nro
        └── lang
            ├── overrides.json
            └── sprites
                └── spr_tutorial_switch_ru.png
```

3. Запустите игру — она будет на русском.

## Удаление

Удалите папку `/switch/spamton_subplot/lang` с SD-карты. Сохранения при этом не пострадают.

## Как это работает

При запуске порт ищет файл `lang/overrides.json` рядом с сохранениями. В нём:

- `strings` — пары «оригинальная строка → перевод». Перевод подставляется при загрузке игры, сама игра (`data.win`) не изменяется.
- `sprites` — замены кадров спрайтов (здесь — русская схема управления).

Чтобы поправить перевод, достаточно отредактировать `overrides.json` любым текстовым редактором (в кодировке UTF-8) и перезапустить игру. Строки, которые игра использует в своей логике (ключи сохранений, сравнения), в перевод специально не включены — их менять нельзя.

## Особенности перевода

- Валюта — «КРОМЕР», здоровье — «ОЗ», цикл (loop) — «ЦИКЛ».
- Надписи в HUD перестроены под русскую грамматику: «ДО МАГАЗИНА: 3» вместо «SHOP IN 3 ROUNDS».
- Названия песен в саундтреке, [[BIG SHOT]], [[SMALL SHOT]], [[Z+ENTER]] и [[JARONA]] оставлены как в оригинале.
- Логотип игры нарисован спрайтом и остаётся на английском.
