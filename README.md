# Spamton Subplot — порт на Nintendo Switch

Неофициальный некоммерческий порт фан-игры по DELTARUNE «Spamton Subplot: Repaid+» (автор — SaRlow) на Nintendo Switch (homebrew).

Игра сделана на GameMaker. На Switch её запускает [Butterscotch](https://github.com/ButterscotchRunner/Butterscotch) — открытая реализация движка GameMaker, которая исполняет оригинальный `data.win` без изменений. Всё, чего не хватало для этой игры, добавлено патчем `switch/patches/butterscotch-port.patch`.

## Что нужно

- Nintendo Switch / Switch Lite / Switch OLED с кастомной прошивкой (Atmosphère) и Homebrew Menu.

## Установка

1. Скачайте `SpamtonSubplot.nro` (вкладка **Actions** → последний запуск **Build Switch NRO** → артефакт `SpamtonSubplot-switch`).
2. Скопируйте его на SD-карту в папку `/switch/spamton_subplot/`.
3. Запустите через Homebrew Menu. Лучше в режиме полного доступа к памяти: удерживайте **R**, запуская любую установленную игру.

Сохранения лежат на SD-карте в `/switch/spamton_subplot/`.

## Русификатор

Лежит в папке [`russian/`](russian/): скопируйте папку `russian/lang` на SD-карту в `/switch/spamton_subplot/`. Подробности — в [russian/README.md](russian/README.md).

## Управление

Кнопки ABXY работают **по положению**, как на геймпаде Xbox, под который сделана игра: стрельба идёт в сторону нажатой кнопки.

| Действие | Кнопки |
|---|---|
| Ходьба | Левый стик или крестовина |
| Стрельба | A / B / X / Y (вправо / вниз / вверх / влево) или правый стик |
| Рывок с неуязвимостью | R, ZR или нажатие левого стика |
| Выбор в меню | B (нижняя кнопка) |
| Навигация по меню | Крестовина |
| Пауза | + |

## Что сделано в порте

- **Нативное разрешение.** В портативном режиме (и на Switch Lite) игра рендерится сразу в 960×720 и выводится на экран 1280×720 пиксель в пиксель, без двойного масштабирования; это ещё и на 44% меньше пикселей для отрисовки. В доке картинка выводится ровно ×2 (1280×960) по центру экрана 1920×1080. Переключение при установке в док и снятии работает на лету.
- **Рамки в стиле локаций.** Вместо чёрных полос по бокам — рамки, собранные из спрайтов самой игры: меню, первая локация, вторая локация и чёрно-белые варианты для лупов. Рамка меняется вместе с локацией с плавным переходом.
- **Шрифт и функции движка.** Добавлены `font_add` (без него в игре не было бы текста), `int64` (на нём держится логика игрока, паузы и боссов) и ещё 11 недостающих функций.
- **Управление под Switch.** Схема в главном меню перерисована: вместо клавиатуры и геймпада Xbox — Switch Lite в стиле оригинального рисунка; подсказки «RT, RB» заменены на «ZR, R».
- **Иконка и название** для Homebrew Menu.

## Сборка

Нужен devkitPro (devkitA64, libnx, switch-sdl2, switch-mesa, switch-ffmpeg). Проще всего собирать в официальном контейнере:

```bash
docker run --rm -v "$PWD":/work -w /work devkitpro/devkita64:latest bash switch/build.sh
```

Результат появится в `dist/SpamtonSubplot.nro`. Скрипт скачивает Butterscotch на зафиксированном коммите, накладывает патч порта, собирает его, кладёт файлы игры и ресурсы порта (`switch/romfs/`) в RomFS и упаковывает NRO с иконкой `switch/icon.jpg`.

Ресурсы порта описаны в `switch/romfs/port/overrides.json`: замены строк, кадров спрайтов и правила выбора рамок.

## Что не работает на Switch

- Пункты меню «JOIN DISCORD» и «PLAY WALLSHMALLOW» открывают ссылки в браузере — на консоли они ничего не делают.
- Ввод сида для забега с сидом рассчитан на клавиатуру.
